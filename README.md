# دو ربات معامله‌گر روی صرافی تبدیل (اهرم کلاسیک تومانی)

این ریپازیتوری، **جدا از** ریپوی سیگنال‌دهی/Paper Trading قبلی‌ات، همون دو
استراتژی رو روی صرافی **تبدیل** اجرا می‌کند — با یک کلید سوئیچ ساده بین دو حالت:

| بات | استراتژی | فایل اجرا |
|---|---|---|
| `bot1_live` | Supertrend + ADX (جهت معکوس، طبق بک‌تست) | `bot1_live/live_trader.py` |
| `bot2_live` | ICT/SMC Scalp Pro v2 | `bot2_live/live_trader.py` |

سیگنال هر دو بات از داده‌ی رایگان بایننس (دلاری) محاسبه می‌شود؛ خودِ فایل‌های
`signal_bot.py` و `signal_bot_v2.py` **بدون هیچ تغییری** از پروژه‌ی قبلی
کپی شده‌اند تا منطق اندیکاتورها دقیقاً همون چیزی بمونه که تست کرده بودی.

نمادهای فعال **ثابت نیستند** — هر بار اجرا، بات خودش با `discover_irt_margin_symbols`
از تبدیل می‌پرسد کدام ارزها (از بین لیست نمادهای هر استراتژی) **همین الان**
بازار تومانی با مارجین فعال دارند، و فقط روی همان‌ها کار می‌کند. یعنی اگه
امروز فقط BTC/ETH فعال باشن ولی فردا یه ارز دیگه هم اضافه بشه، بدون تغییر کد
خودش اضافه می‌شه.

---

## 🔑 دو حالت اجرا — با یک متغیر (`TABDEAL_DRY_RUN`) سوئیچ می‌شوند

### حالت آزمایشی/فرضی — `TABDEAL_DRY_RUN=true` (پیش‌فرض توصیه‌شده الان)
- **هیچ سفارش واقعی ثبت نمی‌شود و هیچ پولی درگیر نمی‌شود.**
- **نیازی به `TABDEAL_API_KEY`/`TABDEAL_API_SECRET` ندارد** — یعنی همین الان،
  بدون اینکه منتظر گرفتن کلید API بمونی، می‌تونی این حالت رو روشن کنی.
- قیمت ورود/خروج و SL/TP از orderbook **واقعی** تبدیل خوانده می‌شود (نه از
  بایننس)، پس نتیجه نشون می‌ده اگه همین استراتژی رو دقیقاً روی همین صرافی
  (با اسپرد و نقدینگی واقعی‌اش) اجرا کنی چقدر سودده می‌مونه.
- هر باز/بسته‌شدنِ پوزیشنِ فرضی در `bot1_live/paper_trades_log.csv` و
  `bot2_live/paper_trades_log.csv` ثبت می‌شود (ستون‌ها: قیمت ورود/خروج،
  SL/TP، سود/زیان فرضی به تومان، موجودی فرضی بعد از هر معامله).
- پیام تلگرام هم می‌فرستد (با پیشوند «[آزمایشی]») تا لحظه‌به‌لحظه ببینی.

### حالت زنده — `TABDEAL_DRY_RUN=false`
- سفارش واقعی با پول واقعی روی تبدیل ثبت می‌شود. نیاز به `TABDEAL_API_KEY`/`TABDEAL_API_SECRET` دارد.
- قبل از روشن‌کردن این حالت، بخش «⚠️ ریسک‌های تاییدنشده» پایین‌تر رو حتماً بخون.

**پیشنهاد من برای الان:** `TABDEAL_DRY_RUN` را روی `true` بگذار و بذار چند
روز/هفته با قیمت واقعی تبدیل بدون ریسک اجرا بشه. بعد از بررسی
`paper_trades_log.csv` هر دو بات، اگه از نتیجه راضی بودی، فقط همین یک
Variable رو به `false` تغییر بده — نیازی به تغییر کد یا ساخت ریپوی جدید نیست.

## ⚠️ ریسک‌های تاییدنشده (فقط برای وقتی خواستی حالت زنده را روشن کنی)

من به مستندات رسمی `docs.tabdeal.org` مراجعه کردم و کلاینت را (برخلاف نسخه‌ی
قبلی که مسیرهایش حدسی/ASSUMED بود) بر پایه‌ی **پکیج رسمی پایتون `tabdeal-python`**
نوشتم — همون پکیجی که خودت هم توی `test_connection.py` بهش رسیده بودی.
با این حال دو نکته هنوز با API واقعی تست نشده‌اند:

1. **فرمت نام بازار.** پاسخ‌های نمونه در مستندات از `"symbol": "BTCIRT"` (بدون
   آندرلاین) استفاده می‌کنند، ولی یک نمونه‌کد در صفحه‌ی پکیج پایتون
   `symbol='BTC_IRT'` نشان می‌دهد. کد این ریپو از فرمت بدون آندرلاین استفاده
   می‌کند؛ اگر با خطای «بازار پیدا نشد» مواجه شدی، اولین چیزی که باید امتحان
   کنی تعویض `symbol=` با `tabdealSymbol="BTC_IRT"` در `common/tabdeal_broker.py` است.
2. **بازپرداخت خودکار وام هنگام بستن پوزیشن.** کد فرض می‌کند وقتی با سفارش
   معکوس پوزیشن را می‌بندی، بدهی قرض‌گرفته‌شده خودکار تسویه می‌شود (الگوی رایج
   صرافی‌های شبیه بایننس). این فرض تاییدنشده است. بعد از اولین معامله‌ی واقعی،
   حتماً با `get_isolated_margin_account()` چک کن که بدهی صفر شده.

حالت آزمایشی بالا این دو ریسک را کاملاً دور می‌زند چون هیچ سفارشی ثبت نمی‌شود.

## مرحله ۰ (اختیاری، همین الان بدون آپلود روی گیت‌هاب): چک سریع نمادها

قبل از هر کاری می‌تونی همین محلی (یا توی Codespace) اجرا کنی تا ببینی از بین
نمادهای دو استراتژی، الان کدوم‌ها روی تبدیل بازار تومانی مارجین‌دار دارن —
این اسکریپت هم به هیچ API Key نیاز ندارد:

```bash
pip install -r requirements.txt
python discover_markets.py
```

## مرحله ۱: ساخت ریپازیتوری جدید در گیت‌هاب

1. یک ریپازیتوری جدید (خصوصی یا عمومی، فرقی نمی‌کند چون در حالت آزمایشی
   هیچ کلید محرمانه‌ای لازم نیست) بساز.
2. تمام فایل‌ها و پوشه‌های همین پروژه (`signal_bot.py`, `signal_bot_v2.py`,
   `common/`, `bot1_live/`, `bot2_live/`, `.github/`, `requirements.txt`) را
   در آن آپلود کن.

## مرحله ۲: تنظیم Variables برای شروع در حالت آزمایشی

`Settings -> Secrets and variables -> Actions -> Variables -> New repository variable`:

| نام Variable | مقدار پیشنهادی برای الان | توضیح |
|---|---|---|
| `TABDEAL_DRY_RUN` | `true` | حالت آزمایشی — بدون پول واقعی |
| `PAPER_STARTING_BALANCE_IRT` | `5000000` | موجودی فرضی شروع (تومان) برای محاسبه‌ی PnL فرضی |
| `TELEGRAM_CHAT_ID` | چت‌آیدی ربات اول | برای دریافت گزارش بات ۱ |
| `TELEGRAM_CHAT_ID_2` | چت‌آیدی ربات دوم | برای دریافت گزارش بات ۲ |
| `BOT1_MARGIN_IRT` | `150000` | مارجینِ فرضی هر معامله‌ی بات ۱ (فقط برای محاسبه‌ی حجم فرضی) |
| `BOT1_LEVERAGE` | `3` | اهرم فرضی بات ۱ |
| `BOT2_MARGIN_IRT` | `100000` | مارجینِ فرضی هر معامله‌ی بات ۲ |
| `BOT2_LEVERAGE` | `2` | اهرم فرضی بات ۲ |

توکن‌های تلگرام (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_TOKEN_2`) را هم به‌عنوان
Secret اضافه کن — یا از همون توکن ربات‌های فعلی‌ات استفاده کن، یا (پیشنهاد
من) دو ربات جدید بساز تا پیام‌های تست تبدیل با سیگنال‌های فرضی قبلی قاطی نشه.

`TABDEAL_API_KEY` و `TABDEAL_API_SECRET` را **فعلاً لازم نداری** — فقط وقتی
خواستی حالت زنده را روشن کنی اضافه‌شان کن.

## مرحله ۳: اجرا و بررسی نتیجه

از تب **Actions** روی هر دو ورک‌فلو (**Bot1 Live** و **Bot2 Live**) بزن →
**Run workflow** برای یه تست دستی؛ بعد بذار زمان‌بندی خودکار هر ۱۵ دقیقه
(از قبل توی هر دو فایل تنظیم شده) خودش ادامه بده. بعد از چند روز:
- فایل‌های `bot1_live/paper_trades_log.csv` و `bot2_live/paper_trades_log.csv`
  را دانلود/باز کن و ببین موجودی فرضی (`balance_after_irt`) نسبت به شروع
  (پیش‌فرض ۵ میلیون تومان) چقدر تغییر کرده.
- پیام‌های تلگرام (با پیشوند «[آزمایشی]») هم لحظه‌به‌لحظه همین را نشون می‌دهند.

## مرحله ۴ (بعداً، وقتی از نتیجه راضی بودی): رفتن به حالت زنده

1. از لینکی که پشتیبانی داد کلید بگیر: https://tabdeal.org/panel/settings/api
   (روی محدودیت IP نزن، چون IP اجراهای GitHub Actions هر بار عوض می‌شود؛
   مطمئن شو دسترسی معاملاتی روی کلید فعال باشه.)
2. `TABDEAL_API_KEY` و `TABDEAL_API_SECRET` را به‌عنوان Secret اضافه کن.
3. `TABDEAL_DRY_RUN` را به `false` تغییر بده.
4. حتماً یک‌بار با **Run workflow** دستی و کمترین مبلغ تست کن، نه مستقیم با
   زمان‌بندی خودکار — و بخش «⚠️ ریسک‌های تاییدنشده» بالا را دوباره بخوان.

## توسعه‌ی بعدی: بازار تتری (پوشش کامل ۱۳ نماد)

لیست `CANDIDATE_BASES` در هر دو فایل `live_trader.py` را می‌توانی گسترش
بدهی یا به بازار تتری منتقل کنی؛ چون کشف نمادها زنده و خودکار است
(`discover_irt_margin_symbols`)، فقط کافیه ارزهای بیشتری به این لیست اضافه
کنی، خودش چک می‌کند کدام‌ها واقعاً بازار مارجین‌دار دارند.
